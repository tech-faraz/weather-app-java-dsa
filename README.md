# 🌦️ Java Weather Application (GUI + DSA)

## 📌 Description

This is an interactive **Java GUI-based Weather Application** developed using Object-Oriented Programming (OOP) and Data Structures & Algorithms (DSA).
The application allows users to search weather information by city and stores search history using file handling.

---

## 🎯 Features

* 🌤️ Search weather by city
* 💾 Save search history (file handling)
* 📊 Efficient data handling using DSA
* 🎨 Graphical User Interface (GUI)
* 🔍 Quick search functionality
* 🧠 Organized data processing
